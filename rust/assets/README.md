# Workflow icon

`icon.png` was generated from scratch for this repository on 2026-11-02 with
the built-in ImageGen tool. No reference image was supplied. It replaces the
icon imported with the earlier Rust implementation and does not reuse the
original project's artwork.

The image has a transparent background outside the rounded tile. It is
embedded by `src/install.rs` and copied to the installed Alfred workflow.

## Generation prompt

```text
Use case: logo-brand. Asset type: original square macOS Alfred workflow icon for an independent developer tool called alfred-jetbrains-rust. Create a new original polished app icon from scratch: a dark graphite rounded-square tile with a bold warm copper-orange project-folder symbol intertwined with two ivory code chevrons, expressing quickly opening coding projects. Restrained dimensional depth, crisp geometric edges, very simple strong silhouette and readable at 32 pixels, generous padding, perfectly centered. 1024 by 1024 square composition. Outside the rounded-square tile must be genuinely transparent. No text, no letters, no watermark, no official JetBrains logo, no Rust gear logo, no Alfred hat, no existing brand marks, no borrowed artwork. Deliver one finished standalone PNG icon, not a mockup, no multiple variants, no surrounding background.
```
